# 采样与神经网络衔接

## 1. 统计对象

当前标签分布由三部分共同形成：

\[
\mathcal L(Y\mid x)=\pi_0(x)\delta_0+\pi_c(x)\mathcal L_c(Y\mid x)+\pi_u(x)\mathcal L_u(Y\mid x),
\]

其中 `0` 表示可计算域内的真实零响应，`c` 表示完整域内的非零响应，`u` 表示当前教师无法给出目标标签的域删失。部件级标签还叠加了结构可达性、命中机会和条件毁伤强度。

该结构应按“域是否完整—是否产生支持—条件响应大小”分层建模。它不同于单一连续长尾，也不能通过一个全局 class weight 完整处理。

## 2. 双臂采样设计

训练数据由两个互补采样臂构成：

| 采样臂 | 作用 | 可回答的问题 |
|---|---|---|
| 分层均匀 Reference | 保存声明参考分布和基准覆盖 | 参考分布下的发生率、校准、分布漂移 |
| V5 Coverage | 增加过渡区、稀有部件和非饱和树输出 | 给定预算下能否提高有效训练覆盖 |

Reference 决定统计基准，Coverage 改善训练效率。两臂共同进入训练时保留来源、分层、一阶纳入概率和原始设计权重；报告发生率时使用 Reference 或明确的回权估计。

## 3. 抽样前代理

### 3.1 方向剂量先验

快速代理对部件 \(j\) 计算期望命中数 \(\lambda_{h,j}\) 与期望侵彻数 \(\lambda_{p,j}\)，再转换为软支持：

\[
p_{h,j}=1-e^{-\lambda_{h,j}},\qquad
p_{p,j}=1-e^{-\lambda_{p,j}}.
\]

代理汇总来向、起爆位置、遮挡、部件暴露和侵彻余量。它用于候选排序和预算分配，不作为教师标签。

### 3.2 包络、严重度与利用率

设部件数为 \(C\)：

\[
U_h=\frac{1}{C}\sum_j p_{h,j},\qquad
U_p=\frac{1}{C}\sum_j p_{p,j},
\]

\[
S=\frac{1}{C}\sum_j\max_k P(z_j=k\mid x),\qquad
s_{raw}=\frac{S}{U_p},\qquad
s=\operatorname{clip}(s_{raw},0,1).
\]

`U_p` 用于划分低包络、过渡和高包络带；67 维部件支持向量用于全局边际覆盖；\(4s(1-s)\) 用于定位转换区。小 \(U_p\) 会放大 `s_raw`，因此选择器使用有界 `s` 和分层标准化，原始比值只用于诊断。

### 3.3 域与饱和风险

冻结风险模型使用抽样前特征估计：

\[
q_{domain}=P(D=1\mid proxy),\qquad
q_{sat}=P(\text{tree saturated}\mid D=1,proxy).
\]

V5 在“来向 × 弹型 × U 带”内使用：

\[
g_i=\sum_k\frac{X_{ik}}{E[n_k]+5}
+0.8z(q_{domain,i})-0.8z(q_{sat,i}).
\]

其中 \(X_{ik}\) 为候选 \(i\) 对部件 \(k\) 的软支持，\(E[n_k]\) 为当前期望支持数。`q_domain` 与 `q_sat` 是软排序特征，不构成硬删除门。

## 4. V5 验证结论

冻结规则见 `artifacts/validation/sampling/PREREGISTRATION_V5.md`，风险模型见 `artifacts/validation/sampling/risk_model.json`。代理与教师结果分别见：

- `artifacts/validation/sampling/v5_proxy_aggregate.json`；
- `artifacts/validation/sampling/v5_teacher_aggregate.json`。

最终 2,000 对 2,000 教师比较得到：

| 指标 | Reference | V5 | V5 − Reference |
|---|---:|---:|---:|
| 完整域率 | 70.25% | 68.70% | -1.55 pp，95% bootstrap CI `[-4.15, 1.10]` pp |
| 完整域内树饱和率 | 54.947% | 49.927% | -5.019 pp，95% bootstrap CI `[-8.195, -1.950]` pp |
| 支持次数至少 20 的部件数 | 65 | 66 | +1 |
| 正支持部件数均值 | 7.631 | 7.773 | +0.142，区间跨 0 |

教师预注册总门结果为 `overall_pass=false`：完整域率非劣区间、正支持部件数改善和支持 Gini 三项门未通过。V5 已验证的优势是降低完整域内饱和并保持广泛部件支持，因此它进入混合设计的覆盖增强臂，不单独替代 Reference。

## 5. 权重分轴

三类权重承担不同统计任务，必须分别存储：

| 量 | 定义 | 使用位置 |
|---|---|---|
| 设计权重 | 候选对目标设计分布的逆纳入权重 | 发生率、校准、加权风险和采样审计 |
| 任务损失权重 | 对稀有任务、量纲或业务损失的权衡 | 训练目标内部 |
| 小批量概率 | 优化器看到样本的频率 | DataLoader/BatchSampler |

小批量概率不得由设计权重隐式推导。过采样、loss reweighting 和设计回权可同时存在，但各自的分母、归一化和有效样本量需要单独报告。

## 6. 推荐模型分解

### 6.1 域头

对全部唯一候选训练域完整性头：

\[
\hat p_D(x)=P(D=1\mid x).
\]

使用二元交叉熵，并在 Reference validation 上报告 ROC-AUC、PR-AUC、Brier、log loss 和校准曲线。域头的标签对所有候选可用。

### 6.2 响应头

响应头只在 `response_mask=true` 的样本上计算损失。建议采用共享骨干与分任务输出：

- 部件支持：67 个多标签 sigmoid；
- 命中/侵彻次数：计数或过度离散计数头；
- 沉积能量：零质量与条件正值分解，正值部分使用 `log1p` 或适合正连续量的似然；
- 部件严重度：有序或连续有界头，按标签定义选择；
- 毁伤树：7 个任务分别建模，保留任务间逻辑约束；
- 摘要量：作为辅助监督，避免与部件标签重复计权。

各毁伤类别的等级 2 应满足等级 1。若模型输出累计概率 \(q_1=P(Y\ge1)\)、\(q_2=P(Y\ge2)\)，必须保证 \(0\le q_2\le q_1\le1\)。可用单调参数化或投影层实现，评价时同时报告有序 Brier、RPS 与阈值级校准。

### 6.3 零值与不可用值

- 真实零：教师完成且输出为 0，可作为负例；
- 域删失：教师未形成完整标签，由 mask 排除响应损失；
- 拒绝：候选未进入教师，保留在采样审计；
- 未定义任务：由任务级 mask 排除。

`NaN` 是数据合同的一部分。训练前应断言 mask 与有限性一致，再进行张量运算。

## 7. 切分与防泄漏

当前数据包按设计种子分组：三个种子用于 train，一个独立种子用于 validation。同一候选组不跨切分，归一化统计只由 train 拟合。

后续冻结模型比较时新增 sealed test，流程为：

1. 冻结输入合同、采样设计、标签版本、训练代码和评价指标；
2. 使用未参与代理拟合、模型选择和阈值选择的新设计种子；
3. 同时生成 Reference test 与受控覆盖诊断集；
4. 只用 Reference test 报告目标设计分布性能；覆盖诊断集用于分层失效分析。

## 8. 训练与评价指标

### 数据覆盖

- 域完整率及置信区间；
- 真实零率、条件非零率与域删失率；
- 每部件支持数、至少 5/10/20 次支持的部件数；
- 支持 Gini、过渡带占比和设计权重 ESS；
- 总体树饱和率与完整域内树饱和率。

### 模型性能

- 二元/多标签：PR-AUC、ROC-AUC、Brier、log loss、校准斜率与截距；
- 有序输出：RPS、阈值 Brier、单调违约率；
- 连续正值：MAE、RMSE、对数尺度误差和分位数覆盖；
- 计数：Poisson/负二项偏差、MAE 和过度离散度；
- 参考分布风险：使用原始设计权重，并同时报告未加权开发性能；
- 分层稳健性：按来向、弹型、U 带、域状态与采样臂报告。

一个采样器的验收需要同时比较总体指标、域完整率和完整域内条件指标。该三联报告可识别由于删失组成变化产生的条件化反转。

## 9. 当前数据使用方式

开发数据包位于 `artifacts/development_dataset/`。推荐流程：

1. 从 manifest 绑定版本、文件哈希、源臂和数据角色；
2. 使用 `feature_schema.json` 构建 15 维输入和输出轴；
3. 先训练域头，再对完整域样本训练响应头；
4. 将 Reference 与 Coverage 的 validation 指标分账，并补充合并训练集指标；
5. 保存模型、训练配置、归一化统计、标签版本和代码提交哈希；
6. 研究结论只覆盖开发数据与声明的软件教师。

下一轮数据生成继续采用 Reference + V5 等预算双臂，并优先补足“来向 × 弹型”中候选不足的单元。增加候选池优先于降低最低纳入概率或让其他单元静默替代。
