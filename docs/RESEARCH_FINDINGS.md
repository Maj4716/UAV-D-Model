# 研究发现

## 1. 综合结论

当前标签稀疏与不均匀主要来自四个可分解机制：接触后的几何可达性、`case × component` 展开造成的稀释、教师适用域删失，以及毁伤树对部件状态的压缩。任务本身确实包含结构零和稀有部件，但早期“多数样本恒零”的程度受采样定义和分析口径显著放大。

现有证据支持以下判断：

1. **几何门是早期大块零支撑的首要来源。** 只约束弹体朝向目标，不能保证破片穿透后覆盖内部部件；首次接触条件采样解决未命中和反向飞行，内部视线、遮挡和有效射束仍决定部件支持。
2. **部件级高零率不等于工况级毁伤罕见。** 一个工况通常只激活少量部件，把工况展开成 67 个部件任务后，零率会自然接近 99%。
3. **当前软件教师未表现出“战斗部整体过弱”。** 在最新完整域样本中，两种采样臂的任一部件支持率均约 99.6%，67 个部件均出现支持，平均正支持部件数约 7.6–7.8；树输出反而存在约 50%–55% 的条件饱和。
4. **毁伤树需要作为标签压缩器单独治理。** 当前树只引用 44/67 个部件，23 个部件不会影响树输出；现行开发数据包有 7 个树任务，覆盖、单调性、过渡区和饱和需要逐任务审计。
5. **覆盖增强采样有效，但不能替代参考分布。** V5 显著降低完整域内树饱和率，同时完整域率改进未被证实，教师预注册总门为 `overall_pass=false`。正确方案是 Reference + V5 双臂。
6. **当前成果是一套通过软件与数据合同验证的开发数据资产。** 目标参数状态仍为 `unverified`，所有结论应绑定当前软件教师、输入合同和数据版本。

## 2. 证据演化

### 2.1 历史 5,000 工况诊断

早期数据把两个接触分支混为同一总体：

| 观察 | 数值 | 解释 |
|---|---:|---|
| 分支 A 无部件命中 | 2,789/2,789 | 当前几何下的零支撑区制 |
| 分支 B 至少命中一个部件 | 2,205/2,211 | 条件于有效分支后，工况级支持并不稀有 |
| 全体 `case × component` 正支持 | 4,113/335,000 | 展开后零率 98.7722% |
| 分支 B 内 `case × component` 零率 | 97.2235% | 单工况只覆盖少数部件 |
| 任一树输出为正 | 2,203/5,000 | 树与几何分支共同决定标签质量 |

该批次揭示了“分支混合”与“分析单位混合”两种人为放大因素。它属于历史机制诊断，不用于估计当前接触条件设计的发生率。

### 2.2 首次接触参考批次

首次接触条件下的 360 个参考工况得到逐门分解：

| 门 | 通过数 | 对总样本的含义 |
|---|---:|---|
| 首次装甲接触 | 360/360 | 设计条件 |
| 至少一个破片命中装甲 | 333/360 | 7.50% 在该门损失 |
| 至少一个破片穿透装甲 | 333/333 | 当前样本下侵彻门无新增损失 |
| 至少一个部件被命中 | 106/333 | 63.06% 在装甲后几何门损失 |
| 至少一个部件状态为正 | 106/106 | 当前样本下状态门无新增损失 |
| 至少一个树输出为正 | 89/106 | 4.72% 在树门损失 |

主要漏斗位于“已穿透装甲，但未命中内部部件”。这把改进优先级指向内部视线、瞄点、射束覆盖和候选分层，而不是先提升源项强度。

### 2.3 多轮覆盖采样

相同 240 例预算下，首轮覆盖增强把出现过正毁伤的部件从 40/67 提升到 58/67；参考、首轮和次轮并集覆盖 62/67。该结果证明采样设计可以显著改变可学习任务数，结构可达性与有限预算下的未检出需要分开判断。

### 2.4 V5 双臂比较

最新教师比较的稳定机器证据为 `artifacts/validation/sampling/v5_teacher_aggregate.json`，预注册规则为 `artifacts/validation/sampling/PREREGISTRATION_V5.md`。

| 指标 | Reference | V5 |
|---|---:|---:|
| 完整域样本 | 1,405/2,000 | 1,374/2,000 |
| 任一部件支持率（完整域） | 99.644% | 99.636% |
| 覆盖部件数 | 67/67 | 67/67 |
| 支持次数 ≥20 的部件 | 65 | 66 |
| 正支持部件数均值 | 7.631 | 7.773 |
| 完整域内树饱和率 | 54.947% | 49.927% |

V5 的树饱和差为 -5.019 个百分点，95% bootstrap 区间 `[-8.195, -1.950]`；完整域率差为 -1.55 个百分点，区间 `[-4.15, 1.10]` 跨 0。V5 提供了可重复的非饱和覆盖收益，完整域率保持依赖双臂与掩码治理。

## 3. 根因分解

### 3.1 几何可达性

来向、首次接触板、起爆点、遮挡关系和目标内部部件布局共同决定支持。接触流形已消除未命中与反向飞行，但仍会产生以下真实几何结果：

- 破片命中装甲后未进入有效内部视锥；
- 穿孔方向与部件包络错开；
- 上游部件或结构遮挡下游部件；
- 某些来向 × 弹型单元只有很少完整代理候选。

因此，下一轮候选扩充应按“来向 × 弹型 × U 带”定位不足单元，而不是只扩大总体候选数。

### 3.2 分析单位

工况级任务、部件级任务和树级任务具有不同分母。360 个参考工况中，任一部件为正的工况为 106 个，但展开为 24,120 个 `case × component` 对后，单部件正支持自然稀释。所有稀疏性报告必须先声明：

- 分析单位；
- 标签可用分母；
- 条件事件；
- 采样臂和设计权重；
- 是否排除域删失。

### 3.3 教师适用域

当前开发数据包的 10,589 个唯一候选中，7,337 个为完整域，3,252 个为域删失。若把删失行填为零，会同时夸大负例率、削弱稀有任务并改变采样器排序。域完整性是独立预测任务，响应头在可用掩码内训练。

### 3.4 毁伤树

树的作用是把部件级状态映射为任务级语义。当前模型覆盖检查显示：

- 目标含 67 个部件；
- 毁伤树引用 44 个部件，覆盖率 65.67%；
- 23 个部件未进入树；
- 当前数据包输出 K1/K2、M1/M2、C1/C2 和 F1，共 7 个任务；
- 完整域内约半数样本落在树饱和端点。

这些事实说明树同时存在“未引用部件”和“端点压缩”。后续树设计应满足：

1. 每个任务有明确部件语义和机理依据；
2. 等级 2 的事件集合是等级 1 的子集；
3. 中间连续门保留过渡信息，最终判定门给出稳定等级；
4. 每个叶、门和输出均报告支持率、条件熵和饱和率；
5. 树版本、定义哈希和标签版本随数据包冻结；
6. 特化阈值由预注册的开发目标选择，并在独立种子上验证。

### 3.5 源项强度

在当前软件教师内，源项整体过弱不是主要解释：有效分支和最新完整域样本都产生了高部件支持，树饱和仍然偏高。源项强度仍会改变侵彻余量、命中后响应和任务等级，但应通过受控因子实验评估，而不是通过全局放大来追求均衡标签。

建议固定几何候选，对以下因子做正交或局部响应面：

- 破片质量/速度尺度；
- 破片数或方向浓度；
- 起爆距离；
- 侵彻阈值族；
- 部件响应阈值族；
- 毁伤树阈值与平滑温度。

主要输出为域完整率、部件支持覆盖、条件正值分布、树过渡占比和树饱和率。每次只调整一个语义层，才能区分“源项不足”“内部几何错位”和“树阈值过紧”。

## 4. 引擎与参数探索结果

稳定摘要位于 `artifacts/validation/engine/acceptance_summary.json`。当前实现已完成时间线、累计空间毁伤、分层传输和在线统计等软件一致性改造；测试与数值闭合支持这些实现按合同工作。

参数候选探索没有产生可晋升项：单点和多工况流程的 `selected_candidate_id` 均为 `null`，多工况状态为 `diagnostic_complete_non_promotable`。诊断排名不能写回注册表。该结果把当前目标参数继续保持为 `unverified`，并保留所有选择门的机器记录。

在线统计与原始重复轨迹给出相同科学摘要。R32 基准中，在线统计中位时间 10.888 s，原始轨迹 11.043 s；轨迹时间开销约 1.42%，Python 峰值内存约为在线模式的 4.10 倍。默认数据生成采用在线统计，需要随机重复收敛研究时再启用原始轨迹。

## 5. 当前数据资产

`artifacts/development_dataset/` 汇总 8 个源臂、16,000 条选择观测和 10,589 个唯一候选。数据包已通过文件哈希、接触输入重算、教师张量重算、掩码、权重、切分泄漏和 train-only 归一化检查。

该数据包支持：

- 采样方法与损失设计研究；
- 域头、部件多标签头、计数头、连续响应头和树任务头开发；
- 训练/验证管线、可重复性和数据治理测试；
- 毁伤树结构与阈值的受控消融。

## 6. 下一阶段实验优先级

1. **补齐树覆盖审计。** 为 23 个未引用部件给出“应纳入/明确不纳入”的任务语义，并解决 F2 是否进入当前任务合同。
2. **生成新设计种子的密封测试。** 冻结模型与评价后执行，Reference test 用于总体性能，覆盖诊断集用于失效分层。
3. **补足稀缺来向 × 弹型单元。** 先扩候选池，再运行 Reference + V5 等预算选择。
4. **运行树—源项二维消融。** 固定案例和随机流，对源项尺度与树阈值/温度进行分层比较。
5. **训练跨栏多任务基线。** 域头使用全部候选，响应头使用完整域 mask，Reference validation 报告加权校准。
6. **登记参数证据。** 191 个目标参数和 `RAW-PI-UNVERIFIED` 的来源、单位、适用域与验证状态进入可机读注册表。

这些实验将把“结构零、有限预算未检出、域删失、树压缩和源项强度”分别转化为可证伪假设。
