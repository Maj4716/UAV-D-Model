04 / Inputs & sampling

输入看起来有 48 维，真正变化的只有 7 维

高维张量并不自动等于高维设计空间。

48case physics

原始物理坐标

变化7 维 · 14.58%
固定40 维 · 83.33%
结构缺失1 维 · 2.08%

变化项仅为起爆位置 x/y/z 与姿态四元数 x/y/z/w；设计的本质自由度为球面方向 2 + SO(3) 姿态 3 = 5。

参考设计覆盖

200 / 2002 m 球面等面积格全覆盖
0精确物理输入重复或跨拆分重复
ESS 5,000纯 p0 等权重，weight CV=0
Train 4,000
Val 500
Test 500

拆分注册表在标签执行前冻结；精确去重通过。但 “域独立”仍未验证，因为目标、部件、装甲和参数集全部固定。

直接影响训练的 P0 问题：原始起爆位置经变换得到“3 个方向分量 + 1 个距离”，而 2 m 距离对 Train 是常量。当前路径级角色把四个派生量都标为 learnable，因此严格归一化器正确拒绝： declared learnable_variable feature 'detonation_distance_m' is missing or constant on Train。
05 / Labels & uncertainty

稀有事件、平台和标签冗余决定了“学到什么”

下图的稀有事件以 5% 为满刻度；选择拆分可看有效事件数。

系统标签的信息结构

联合众数平台67.18%
mission_degraded vs mission_loss Spearman0.99689
mission_loss == combined.failed100%
命中数 = 穿透数的案例99.70%
普通 MSE/BCE 很可能通过预测主平台获得“看起来不错”的总体指标，却完全没学会命中—穿透转变。

R=4 重复信息

重复间系统输出有变化370 / 5,000
任一系统标签 CI 半宽 ≥ 0.1083
任一系统标签 CI 半宽 ≥ 0.2562

不确定性边界

mission_loss 最大 CI 半宽约 0.4983；mission_degraded 约 0.2333。

大量平台样本的零宽区间不意味着整个模型的不确定性很小。

聚合顺序是标签语义

63 / 5,000 案例中，“先对叶子取均值再套树”与“每个重复先套树再取均值”不同，最大差 0.111258。

训练和后处理应直接使用归档的系统树输出。

06 / Deep-learning impact

哪些信息会直接改变深度学习效果

可按优先级筛选。P0 是开始标准训练前的阻断项，P1 影响可学性与评估可信度。

特征角色与归一化

P0

2 m 常量距离被当成可学变量，Train-only normalizer 已 fail closed。影响：标准训练视图无法产生；若强行加 epsilon，将制造伪方差和不稳定尺度。

标签语义与损失

P0

system_y 是重叠的事件概率，不是互斥类别。影响：应用独立 sigmoid + soft BCE/Brier；softmax/多类交叉熵会破坏语义。

有效输入维度过窄

P1

48 个物理坐标中只有 7 个变化，且目标/材料/装甲均固定。影响：模型可能轻松插值并获得很低 loss，但不具备跨距离、装药、材料或拓扑泛化证据。

主平台与样本不平衡

P1

67.18% 样本在相同系统联合输出上，破片命中仅 3.84%。影响：总体 MSE/BCE 会偏向常数基线；需同时报告平台基线、事件条件误差、PR-AUC/Brier 和校准。

验证/测试稀有事件太少

P1

Test 只有 17 个命中、4 个“遮蔽且命中”；命中数大于穿透数的 15 个案例全在 Train。影响：关键机理的失败可能无法被验证集发现。

多任务标签信息秩低

P1

两个系统输出 Spearman=0.99689，命中与穿透也几乎退化为同一任务。影响：平权多任务 loss 可能重复优化同一信号，掩盖稀有机理。

Mask 与结构缺失

P1

fixed_initial_velocity_mps 是结构缺失，各类 label/source mask 也是合同的一部分。影响：将缺失填 0 且丢弃 mask，会把“不适用”误学为物理零值。

采样权重的语义

P1

当前全部 p0 且 1/rho=1。影响：未来加入 targeted/adaptive 训练样本时，原始设计权重用于总体估计，不能当成类别权重或 minibatch 抽样概率。

条件随机性与认识不确定性

P1

R=4 重复共用一个 parameter realization hash。影响：当前 CI 主要表示条件 aleatory 随机性，不包含参数认识不确定性；不能当作现实预测区间。

计划文件膨胀

P2

3.72 GiB 的 formal_cases.jsonl 重复嵌入大型 split registry。影响：对当前 5k 训练精度无直接改变，但会限制 50k/300k 数据生成、IO 和检查点性能。

跨格式合同

P2

当前 Parquet 使用版本化显式 schema，首分片已观察到 Fréchet 嵌套界字段。影响：避免表格消费者丢失后行才出现的标签字段；正式训练前仍应保留全分片跨格式一致性门禁。

07 / Action order

如果目标是可信的深度学习，建议按这个顺序推进

已完成
软件归档与原始 Loader
5,000 案例、10 分片、三拆分全量遍历通过。
P0-1
修复 transform-output 特征角色
期望 51 个最终特征：9 learnable + 41 fixed_context + 1 structural_missing；重新生成版本化训练视图。
P0-2
分离 p0 Reference 与 targeted Train
Validation/Test 保持结果盲 p0；只在 Train 用标签前几何类别加强稀有机理。
P0-3
按稀有事件精度设计独立测试集
500 条 Test 只有 17 个命中，不足以稳定估计命中—穿透转变性能。
P1
机理分阶段多任务建模
几何/路径 → 命中 → 条件穿透 → 局部响应 → 直接监督的系统树输出。
P1
建立物理 V&V 和研究准入
独立试验标定、留出验证、机理分层误差与外推失败规则齐备后，才能谈真实效果。

训练开始前的最小验收集

1. 数据处理
Train 拟合归一化，Validation/Test 只应用；常量特征保持 identity；所有 mask 同步进入模型或 loss。
2. 基线与损失
报告联合众数/常数预测基线；系统事件用 soft BCE/Brier；多量纲辅助目标分别标准化和加权，不直接相加。
3. 评估
分别报告 p0 Reference 总体性能、稀有事件条件性能、校准、PR-AUC/Brier、最差几何层与区间不确定性；不将 targeted 和 p0 Test 合并成一个分数。
4. 模型边界
明确声明只适用于固定目标、固定战斗部/材料/环境下的 2 m 球壳 × SO(3) 参考域；空间之外应拒绝预测或标记 OOD。
5. 证据边界
模型能拟合 synthetic teacher，不证明 teacher 物理正确。测试通过、低 loss、高 R² 和较窄的条件 Monte Carlo CI 均不能单独建立真实效度。
