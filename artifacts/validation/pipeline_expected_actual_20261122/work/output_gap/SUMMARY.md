# 输出、标签与毁伤树层预期—实际分布差距

## 分析范围

本分析使用正式数据集的 2,000 个 train 工况和 300 个 validation 工况，共 25,600 个教师重复、67 个部件。300 个 sealed-test trace 行只计数、不调用 `json.loads`，结果解码数为 0。分析没有启动训练。

这里的“预期”分为三类：

1. **冻结合同预期**：train=R8、validation=R32；fragment-only 的 blast 状态为零；combined 状态等于 fragment；`failed≤degraded`；标签等于逐重复聚合；毁伤树按每个重复先计算、再跨重复求均值。
2. **同一 Reference estimand 的切分预期**：train 与 validation 都来自 S-CONTACT 条件分布，但使用不同 QMC 流和 R8/R32 教师精度，因此只做描述性分布差距与条件 bootstrap。
3. **快速代理预期**：`FastSamplingProxy` 的确定性期望与软件教师实际输出比较。

没有外部物理/作战输出分布，因而真实分布差距仍不可估计。

## 1. 冻结合同与实际结果

| 环节 | 预期 | 实际 | 差距 |
|---|---|---:|---:|
| 重复协议 | train R8，validation R32 | trial count 分别仅为 8、32 | 0 |
| fragment-only blast | blast degraded/failed 全为 0 | 3,430,400 个状态值中非零 0 | 0 |
| combined 状态 | 与 fragment 相同 | 3,430,400 次比较不一致 0 | 最大误差 0 |
| 状态嵌套 | `failed≤degraded` | 5,145,600 次比较违规 0 | 0 |
| 状态取值域 | 所有机制状态位于 [0,1] | 10,291,200 个值越界 0 | 0 |
| `p_hit` 聚合 | success/trial | 最大绝对误差 4.44×10⁻¹⁶ | 数值精度内一致 |
| `p_degraded` 聚合 | fragment trace 均值 | 最大绝对误差 5.55×10⁻¹⁶ | 数值精度内一致 |
| `p_failed` 聚合 | fragment trace 均值 | 最大绝对误差 5.55×10⁻¹⁶ | 数值精度内一致 |
| 概率嵌套 | `p_failed≤p_degraded≤p_hit` | 153,361 个共同可识别对违规 0 | 0 |
| CI/识别区间 | 包含点估计，mask 与 ε=0.01 一致 | 三头所有违规均为 0 | 0 |
| 毁伤树 | 冻结树逐重复离线重算 | 179,200 个输出比较不一致 0 | 最大误差 0 |

这部分结果表明，从逐重复机制状态到标签与毁伤树输出的确定性软件映射完整一致。它验证的是实现与数据合同，不是物理模型真实性。

## 2. 实际标签分布

### 2.1 case-component 对

| 输出 | 可识别对数 | 均值 | 标准差 | 零质量 | 一质量 |
|---|---:|---:|---:|---:|---:|
| `p_hit` | 153,615 | 0.091729 | 0.270256 | 87.279% | 6.480% |
| `p_degraded` | 153,515 | 0.077014 | 0.245277 | 87.336% | 1.411% |
| `p_failed` | 153,361 | 0.043304 | 0.183910 | 87.424% | 0.569% |

三个概率输出都呈明显零膨胀。部件对平铺后的 Spearman 相关为：`p_hit–p_degraded` 0.99936、`p_hit–p_failed` 0.99878、`p_degraded–p_failed` 0.99975；Pearson 分别为 0.96878、0.77753、0.85988。高秩相关来自同一命中—退化—失效有序机制，幅值关系仍存在明显差异。

### 2.2 固定 67 部件分母与联合结构

为避免删失使每个工况的分母变化，工况均值的主统计对 67 个部件的识别区间先求平均。该处理保留全部 2,300 个开发工况，不将 mask=false 强行记为零。

| 输出 | train 均值识别区间 | validation 均值识别区间 | validation−train 识别区间 |
|---|---:|---:|---:|
| `p_hit` | [0.091521, 0.091822] | [0.092562, 0.093083] | [+0.000740, +0.001563] |
| `p_degraded` | [0.077163, 0.077536] | [0.077180, 0.077761] | [−0.000357, +0.000599] |
| `p_failed` | [0.043789, 0.044319] | [0.042836, 0.043601] | [−0.001483, −0.000188] |

67 个部件的 `p_hit` 平均值范围从 component-020 的 0.003925 到 component-068 的 0.609429。部件间 `p_hit` 相关的绝对值中位数为 0.0541，p95 为 0.3009；最强相关对为 component-045 与 component-050，Pearson=0.7202。该相关结构是软件教师的实际联合输出特征，项目没有声明“部件独立”的目标。

### 2.3 条件正值输出

| 输出 | 可观察值数 | 均值 | 中位数 | p95 | 解释 |
|---|---:|---:|---:|---:|---|
| `conditional_log1p_energy` | 16,781 | 8.773609 | 8.598148 | 12.427753 | 命中且域点识别的部件对 |

## 3. train 与 validation 的实际分布差距

两个 split 针对同一 S-CONTACT Reference estimand，但 validation 使用 R32、train 使用 R8。固定 67 部件分母的 5,000 次独立工况重采样与识别区间外包络为：

| 输出 | 识别的 validation−train 区间 | 95% case-resampling 外包络 | complete-67 工况数 train/validation | complete-67 均值差（95% case-resampling 区间） |
|---|---:|---:|---:|---:|
| `p_hit` | [+0.000740, +0.001563] | [−0.006261, +0.008664] | 1,955/283 | −0.000500 [−0.007713, +0.006716] |
| `p_degraded` | [−0.000357, +0.000599] | [−0.006535, +0.007092] | 1,909/278 | −0.000893 [−0.007370, +0.005500] |
| `p_failed` | [−0.001483, −0.000188] | [−0.005590, +0.004217] | 1,861/270 | −0.002475 [−0.006712, +0.001919] |

三个外包络均包含 0，支持“当前有限工况下未见大的整体 split 偏移”。按部件计算的 `p_hit` W1 中位数为 0.007211、p95 为 0.024291、最大值为 component-049 的 0.034967；15 个 region×profile 单元的 train–validation 质量 TV 为 0.055。

按每个工况“已观测部件”求均值会得到 +0.007005/+0.005906/+0.006066，但观测部件数与输出均值明显相关。这组数字只作删失敏感性诊断，不作 split drift 主证据。R8/R32 还会改变 Monte Carlo 离散化、零质量和识别能力，因此该比较仍是条件于当前设计的开发期描述。

## 4. region×profile 分层

15 个单元全部在开发集中出现。固定 67 部件分母后，三头最低单元均为 `pos_y::small_front`，且点识别：`p_hit/p_degraded/p_failed` 为 0.018284/0.013577/0.005193。

`p_hit` 的最高单元可识别为 `neg_y::large_front`，区间 [0.135714, 0.135856]。`p_degraded` 与 `p_failed` 的 `neg_x::large_front` 与 `neg_y::large_front` 识别区间重叠，不对两者强行排序；`neg_y::large_front` 的区间分别为 [0.121886, 0.122078] 和 [0.082766, 0.083166]。这些分层差异是当前合成教师的输出特征，不代表现实作战发生率。

原可变分母结果将 `neg_x::large_front` 的 `p_hit/p_failed` 抬高至 0.150775/0.097532；该结果已降级为删失敏感性诊断。

## 5. 毁伤树实际分布与映射差距

冻结树的 179,200 个逐重复输出均能从 component mechanism state 精确离线重算。七个输出的开发集分布如下：

| 输出 | 均值 | 零质量 | p95 | train–validation W1 | validation−train 均值 |
|---|---:|---:|---:|---:|---:|
| `effect-m2` | 0.580206 | 15.087% | 1.000000 | 0.008835 | −0.000990 |
| `effect-k1` | 0.038549 | 74.391% | 0.185917 | 0.003476 | +0.001114 |
| `effect-m1` | 0.212929 | 53.609% | 1.000000 | 0.012962 | −0.010122 |
| `effect-k2` | 0.011637 | 83.609% | 0.014204 | 0.004849 | −0.002211 |
| `effect-f1` | 0.187052 | 51.217% | 0.999681 | 0.020996 | −0.020976 |
| `effect-c1` | 0.465914 | 39.565% | 1.000000 | 0.010520 | −0.000885 |
| `effect-c2` | 0.240263 | 39.565% | 0.999692 | 0.025994 | −0.025557 |

七个 validation−train 均值差的 95% case-bootstrap 区间全部包含 0。较大的 W1 出现在 `effect-c2` 和 `effect-f1`；这些是后续独立设计复核的优先输出。项目没有为七个树输出声明外部目标发生率，因此这里只能验证映射一致性与切分漂移，不能评价树输出是否贴近现实。

## 6. 快速代理预期与软件教师实际分布

在 153,615 个可识别 case-component 对上：

- Brier=0.042257，95% case-cluster CI [0.040911, 0.043630]；
- ECE=0.051290，95% case-cluster resampling 区间 [0.049738, 0.052826]；
- 固定分箱 JS=0.012090，95% case-cluster resampling 区间 [0.011612, 0.012613]；
- 正能量 `log1p` W1=1.164528，仅覆盖代理与教师同时为正的部件对；
- 67 维命中概率 RBF-MMD²=0.042253；
- R8 train false-unreached=7.605%，R32 validation=9.229%。

这些数值量化了代理预期与软件教师实际分布的差距。它们衡量的是 soft-label agreement，并包含有限重复的教师 Monte Carlo 误差。

## 7. 证据边界

正式运行的 `capture_fragment_audit=false`，所以完整 2,600 例归档上无法恢复破片生成→装甲相交→遮挡→侵彻的逐事件漏斗。本轮另建了 30 个 train-only 固定分层微观审计，结果见 `work/mechanism_funnel/micro_audit_metrics.json`；该等层诊断不外推为完整开发总体率。完整开发 trace 从部件机制状态开始，可以严格验证状态聚合、标签和毁伤树。

Taylor–Shapiro、高斜率约束、材料响应和真实入射分布缺少外部观测。因此当前能够成立的是：

- 机制状态→标签→毁伤树的软件映射与冻结合同一致；
- 标签、树输出、split drift 和 region×profile 异质性已被量化；
- 快速代理与软件教师存在稳定差距；
- 软件教师与真实物理/作战分布的差距仍没有可计算的实际分母。

机器可读结果见 `output_gap_metrics.json`，复算脚本见 `analyze_output_distribution_gap.py`。
