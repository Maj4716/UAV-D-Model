# 各向异性三级快速评估：实现与量化评估报告

## 1. 结论

各向异性球方案已经封装为可独立运行的快速评估方法。默认 `quick` 只执行 L1 生成器诊断与 L2 方向性暴露代理，不构建正式数据集、不运行随机教师、不读取封存测试结果；`calibrate` 只读取带角色和来源审计的既有教师证据执行 L3 固定工况比较。

当前结果把两类问题清楚分开：

- **生成器侧存在测度迁移。** 15 个 region×profile 单元声明为等质量，S-CONTACT 实现分布相对声明分布的总变差距离为 **0.200781**，超过 0.10 诊断门；最大均匀边际 KS 为 **0.146919**，也超过 0.10。
- **代理侧存在适用域和教师残差。** 代理完整域比例为 **0.570313**；256 条混合开发证据上的加权概率 RMSE 为 **0.206398**，Spearman 为 **0.591166**，false-unreached 为 **0.078985**，均未达到当前诊断门。
- **结论在 train 与 validation 两个角色中方向一致。** 229 条 train 与 27 条 validation 分别得到 RMSE 0.205123/0.216916、Spearman 0.587317/0.619423；两者均显示代理相对教师低估。
- **当前 L3 不能归因到当前引擎实现。** 目标与物理注册表身份匹配，但教师引擎代码哈希与当前代理代码哈希不同。现有证据证明“当前代理与已有软件教师存在差距”，不能把全部差距归因于当前仿真引擎。

工程可行性成立；当前版本适合作为生成器和代理/教师残差的快速诊断工具。研究晋级前需要补充当前源身份完全匹配的固定工况教师校准，以及外部物理参照。

## 2. 三级结构与解耦边界

| 层级 | 输入 | 核心输出 | 是否运行教师 | 定位对象 |
|---|---|---|---:|---|
| L1 生成器 | 工况、潜变量、设计权重 | 经验各向异性椭球、KS、单元质量、选择足迹 | 否 | 候选生成、接触条件化、选样和权重 |
| L2 暴露代理 | 工况、目标几何、Taylor/Taylor-Shapiro 方向核 | 部件暴露量、损伤能量、有限帧可达性、适用域 | 否 | 方向离散、遮挡、侵彻接口和代理分辨率 |
| L3 引擎校准 | 固定工况 L2 结果、已有非测试教师行 | 概率误差、秩相关、false-unreached、分层残差 | 否，仅仅读取既有证据 | 代理—软件教师残差 |

这里的“各向异性球”由两部分组成：潜变量空间中的经验椭球，以及物理空间中的方向性射线暴露核。它不是忽略方向、遮挡和侵彻阈值的各向同性距离衰减球。

L1 与引擎完全分离。L2 不调用随机教师，但复用目标几何、空气阻力和侵彻响应，因此实现的是流程隔离与残差定位，不是外部独立物理模型。L3 在同一批固定工况上比较 L2 与软件教师，使生成器变化不再混入引擎残差。

## 3. 量化定义

对潜变量向量 \(z_i\) 和设计权重 \(w_i\)，L1 使用

\[
\mu=\frac{\sum_i w_i z_i}{\sum_i w_i},\qquad
\Sigma=\frac{\sum_i w_i(z_i-\mu)(z_i-\mu)^\top}{\sum_i w_i},
\]

并以 \(r_i^2=(z_i-\mu)^\top\Sigma^+(z_i-\mu)\) 描述经验各向异性半径。该方法报告特征值、有效秩、经验半径分位数、边际 KS 和占箱率，不假设数据服从高斯分布。

L2 对部件 \(j\) 聚合方向射线包得到候选级 \(\lambda_{ij}\) 与损伤能量，再按声明测度计算 Hájek 均值。L3 使用 \(p_{ij}^{proxy}=1-\exp(-\lambda_{ij})\) 与既有教师概率逐工况、逐部件比较。

声明单元质量 \(q_c\) 与实现质量 \(\hat q_c\) 的差距采用

\[
TV(q,\hat q)=\frac12\sum_c|q_c-\hat q_c|.
\]

同一批 256 配对样本上的控制变量报告给出中位方差缩减 **0.339920**、中位教师样本等效倍数 **1.514968**。这是同样本探索性估计；validation 子集的对应中位数只有 0.105323 和 1.093103。独立验证前不据此削减正式教师预算。

## 6. 快评近似性与速度

历史冻结 X1 缓存的 4,096/100,000 对照只用于评估方法近似性；缓存文件哈希匹配，但其源码与当前版本不同。

|---|---:|

| 最大 KS 绝对误差 | 0.000109 |
| 潜变量均值 L2 差 | 0.010724 |
| 协方差相对 Frobenius 差 | 0.046592 |
| 完整域比例误差 | +0.005577 |
| 暴露量 Pearson / Spearman | 0.999492 / 0.989776 |
| 能量 Pearson / Spearman | 0.999873 / 0.970446 |
| 到达部件 precision / recall | 1.000000 / 0.967742 |

快评遗漏的稀有到达部件为 component-020 和 component-034，说明全局结构可快速恢复，稀有尾部仍需专门富集。

速度口径必须分开解释：

- 当前源码重新计算 256 例 L1+L2 用时 38.104 s。
- 历史缓存上重算 4,096 行统计只需 1.260 s，但不包含射线暴露生成。
- 当前 48 例、5 次交替顺序微基准中，exposure-only 与 full 的共享暴露字段完全一致；中位配对速度比为 0.963×，没有显示稳定加速，且单次波动较大。

因此 `output_scope="exposure"` 的主要价值是明确计算合同和避免无用树输出；当前证据不支持把它作为显著性能提升。快速方法的主要节省来自不运行随机教师、不构建正式数据集，以及复用已冻结暴露缓存。

## 8. 独立优化闭环

| 观察 | 归属 | 下一步 |
|---|---|---|
| L1 TV/KS 或单元样本门失败 | 生成器 | 明确目标测度帧；在实现帧直接生成或按条件接受率补偿；保留声明/实现/训练三套测度 |
| L1 通过、L2 完整域低 | 快速代理 | 对 top_cap 与 neg_x 自适应角向加密；按 region×profile 记录适用域并建立复核队列 |
| L1/L2 稳定、L3 false-unreached 高 | 代理—教师接口 | 用当前完全匹配源码重跑固定工况教师；按单元和部件定位方向核、遮挡与侵彻差异 |
| 软件一致、外部数据不符 | 物理模型 | 使用实验或现场参照校准参数与机理 |

生成器优化不需要等待教师；代理优化可在固定工况上进行；引擎优化只在 L1/L2 输入身份冻结后评价。这样可避免通过改变数据分布掩盖代理误差，也可避免把条件化偏差错误归因给仿真引擎。

## 9. 可行性判决

- **工程封装：通过。** 两个公共 API、两个 CLI 模式、严格 JSON/哈希、角色检查和零测试解码边界已经建立。
- **快速全局分布评估：可行。** 历史 4,096/100,000 对照支持对全局分布和暴露场结构的快速近似。
- **稀有尾部评估：有条件可行。** 需要单元最小样本门、稀有部件富集和独立尾部召回门。
- **生成器/仿真链路解耦：诊断上可行。** L1 完全引擎无关；L2/L3 通过固定工况把生成器变化与代理—教师残差分开。
- **当前引擎归因：未完成。** 需要当前代码哈希完全匹配的教师证据。
- **外部物理有效性：未判定。** 需要独立实验或现场参照。
