# 工件目录

- `development_dataset/`：当前神经网络开发数据包。大体积 `.gz`/`.npz` 文件本地保留并默认忽略，轻量契约、manifest、验证报告和读取器可进入代码审查。
- `validation/`：长期保留的紧凑机器证据；`manifest.json` 记录文件哈希、大小、范围和状态。
- `refactor_20261117/`：本次清理重构的前后基线、删除清单与验收记录。
- `experiments/`：可再生探索运行，默认忽略。

只有能支撑当前文档结论且具有稳定身份的结果进入 `validation/`；中间候选池和临时日志不作为长期引用目标。
